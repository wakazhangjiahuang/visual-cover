# Layout DNA Engine

## 目标
建立封面、主图、社媒视觉的可检索设计规则。

## Layout DNA字段

### 构图
- 画布比例
- 主视觉占比
- 标题区域
- 辅助信息区域
- CTA区域

### 字体系统
记录：
- 字体类别
- 粗细等级
- 标题层级
- 描边方式
- 阴影方式
- 阅读距离

### 色彩策略
记录：
- 主色
- 辅助色
- 强调色
- 对比关系
- 平台适配

## 封面风格标签

已录入方向：

1. 爆款大字压顶
2. 巨字拆分冲击
3. 小白科普问答
4. 教程清单
5. 产品测评榜单
6. 种草推荐
7. 贴纸拼贴
8. 黑底效率工作流

## 调用原则

参考图只用于分析：
- 版式关系
- 信息层级
- 节奏
- 视觉方法

禁止：
- 复制原图元素
- 复制品牌资产
- 直接复刻商业模板
