# Visual Cover 开源项目适配地图 V1

记录真实开源项目，并提炼可进入 visual-cover 系统的能力模块。

---

小红书封面生成方向项目。

- 标题区域规划
- 平台内容适配思路

适配位置：
Platform Intelligence / Xiaohongshu

Skill化的小红书内容生成流程参考。

- references知识调用方式
- 任务输入输出规范

视觉设计Agent架构参考。

→ Creative Direction
→ Layout Planning

# 4. PosterGen / PosterMELD方向

可提炼：

---

# 集成原则

开源项目只用于：
- 架构参考
- 方法提炼
- 规则学习

禁止：
- 复制代码资产
- 复制模板视觉
- 复制商业设计

visual-cover最终目标：
素材分析 → 规则提炼 → Layout DNA → GPT Image 2.5生成 → 评价优化
