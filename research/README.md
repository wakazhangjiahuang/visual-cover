# visual-cover research knowledge base

## 资料分类原则

本目录不是简单收藏目录，而是供 `$visual-cover-studio` 检索的研究知识层。

分类：

- opensource/：开源项目分析与可复用设计规则
- platform-rules/：自媒体平台规则与内容视觉约束
- layout-dna/：版式、字体、色彩、组件规律
- evaluation/：A/B测试评价体系

## 数据边界

- 记录项目真实存在的能力与结构
- 提炼可迁移的方法，不复制项目代码、品牌资产或商业模板
- 图片、模板、字体等资产需要标明来源和授权状态

## 调用关系

素材分析 → 平台规则 → Layout DNA → Visual Brief → GPT Image 2.5生成 → A/B评价
