# atutun-xhs-cover 项目分析

## 来源
GitHub: panggungunvibe/atutun-xhs-cover

## 定位
小红书封面视觉提示词 Skill。核心价值是将封面类型、标题、人物、素材、构图、色彩规则转化为可执行生成规范。

## 可提取能力
- 封面类型路由
- 标题优先级设计
- 信息密度控制
- 视觉元素组合规则
- Prompt结构化表达

## Visual Cover适配
用于：
1. Cover Style Router
2. Layout DNA Engine
3. GPT Image 2.5 多方案生成

## 不迁移内容
不复制原项目生成结果、品牌元素、具体模板图片。
只提取设计方法、结构和规则。
