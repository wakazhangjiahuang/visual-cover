# xhs-cover-lab-open-skill 项目分析

来源：atian-create/xhs-cover-lab-open-skill

## 项目定位

该项目不是图片生成器，而是封面诊断和设计规划 Skill。

核心问题：

- 这张封面属于什么类型？
- 为什么用户会点击？
- 哪些结构可以学习？
- 哪些元素不能复制？

## 核心工作流

参考封面输入
→ 封面类型识别
→ 赛道路由
→ Cover Brief
→ 图片生成规划

## 提取能力

### Cover Archetype

封面类型库：

- 人物+关键词
- 工具/场景证明
- 知识卡片
- 产品使用场景
- 清单合集

### Track Router

根据赛道匹配封面：

- AI工具
- Agent
- 创作者运营
- 好物分享
- 教育干货

### Benchmark Rules

分析：

- 一秒点击理由
- 关键词
- 视觉证明
- 可学习点
- 不可复制点

## visual-cover适配

进入：

visual-analysis
cover-routing
reference-extraction

## 边界

不负责：
- 实时数据爬取
- 图片生成接口
- 爆款保证

用于生成前策略判断。
