# xiaohongshu_skills 项目分析

## 项目定位

面向小红书图文内容生产的 Skill 体系。

## 可提取模块

### 主题资产

通过 themes 管理视觉主题。

### 规格系统

通过 specs 管理输出规格。

### 生成流程

内容主题
→ 页面结构
→ 图像/卡片设计
→ 输出资源
