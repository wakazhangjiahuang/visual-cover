# Poster Agent Framework Analysis

## 研究对象
- PosterBoy
- PosterGen
- PosterMELD
- poster-design-mcp

## 核心方向

从图片生成升级为设计 Agent。

流程：

视觉理解
↓
创意规划
↓
版式生成
↓
字体处理
↓
视觉评价
↓
优化修复

## 可提取模块

### Vision Analysis

识别：
- 主体
- 层级
- 空间关系
- 风格元素

### Layout Agent

规划：
- 网格
- 留白
- 标题区域
- 图文比例

### Critic Agent

评价：
- 可读性
- 平衡
- 品牌一致性

## visual-cover适配

用于：
GPT Image 2.5生产前的规划层。

不是直接生成图片，而是先生成 Design Brief。

## 禁止

不复制论文/项目生成结果。
