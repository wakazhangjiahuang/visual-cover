服务 visual-cover 的 Layout DNA Engine、视觉规划和生成评价。

## 可提炼能力

### 1. Cover Brief

输入：
- 平台
- 内容类型
- 标题
- 人物/产品素材
- 目标情绪

输出：
- 构图
- 标题层级
- 视觉元素
- 生成约束

### 2. Layout DNA

记录：
- 标题位置
- 主视觉比例
- 信息密度
- 卡片结构
- 标签系统

### 3. Prompt工程

采用：
画面主体 → 标题 → 素材 → 背景 → 装饰 → 构图 → 限制条件

## visual-cover应用边界

允许：
- 学习工作流
- 学习版式逻辑
- 学习评价方法

禁止：
- 复制项目图片
- 复制商业模板
- 复制Logo和品牌视觉
