# PosterBoy 项目分析

## 项目定位
自主设计导演系统。

## Agent流程
Image → Vision → Creative Director → Copywriter → Typography → Layout → Critique Loop

## 核心提取

### Vision Agent
分析主体、空白区域、安全区域。

### Creative Director
生成多个设计方向并选择方案。

### Typography Agent
负责字体组合、字号、字重。

### Layout Agent
负责位置坐标和空间组织。

### Critique Loop
生成后检查并修复。

## visual-cover应用
用于封面A/B测试：
方案生成 → 视觉评分 → 修正。

## 禁止
不迁移具体海报内容，仅学习Agent工作流。
