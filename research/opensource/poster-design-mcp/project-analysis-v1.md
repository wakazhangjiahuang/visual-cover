# poster-design-mcp 项目分析

## 项目定位
MCP 形式的海报设计系统，目标是从自然语言 brief 生成可打印 PNG/JPG 海报。

## 可提取能力

### Design System
- 将参考海报提炼为可计算设计规则
- 布局不是随机生成，而由模板和设计参数控制

### Layout
- 模板化布局
- 边距比例
- 标题尺寸
- 图片裁切
- 信息层级

### Typography
- 自动适配标题尺寸
- 字体层级控制
- 保证文字可读性

### Color
- 根据品牌色生成调色板
- 保持对比度

## 对 visual-cover 的价值
适合作为 Layout DNA Engine 参考：
参考图 → 提取规则 → 参数化模板 → 多方案生成。

## 不直接复制
不复制海报模板、文字和图片资产，只提取设计规则。
