# Layout DNA Engine

## 目标
为 visual-cover 提供版式、字体、色彩检索规则。

## Layout DNA字段
- 比例
- 信息层级
- 标题区域
- 主视觉区域
- 辅助模块
- 留白节奏
- 视觉动线

## Font System
- 超粗标题字体：用于高点击封面
- 圆润字体：用于亲和、母婴、插画类
- 科技字体：用于AI产品、工具类
- 手写字体：用于情绪、生活方式类

## Color Strategy
- 高对比色：提高缩略图识别
- 品牌色：保持一致性
- 辅助色：区分信息模块

## Reference Rule
参考图片只提取方法，不复制角色、Logo、图片、文字和专属视觉元素。
