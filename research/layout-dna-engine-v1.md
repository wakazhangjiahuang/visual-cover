# Layout DNA Engine 版式知识库 V1

## 目标

将参考UI/封面图转化为可执行设计规则，而不是复制视觉结果。

输入：
- 参考封面
- UI截图
- 品牌资料
- 行业场景

输出：
- Layout DNA
- Typography System
- Color Strategy
- Component Rules

---

# Layout Analysis Framework

## 1. 比例系统

分析：
- 画布比例
- 主视觉占比
- 标题区域比例
- 留白比例

---

## 2. 信息层级

一级：
核心标题/核心卖点

二级：
解释信息

三级：
品牌、标签、辅助元素

---

## 3. 字体系统

提取：
- 字体性格
- 粗细关系
- 大小比例
- 对齐方式

规则：
字体风格服务信息传播，不迁移原作品字体资产。

---

## 4. 色彩策略

提取：
- 主色关系
- 强调色逻辑
- 背景策略
- 对比关系

禁止：
直接复制参考图完整配色。

---
